## 3. D-AR-2 — The regime law (lane-side)

**Decision.** The technical lane kernel computes, over the fetched candle window it already holds:

1. **The ATR series**: the in-window ATR-14 observations under the same Wilder computation that today yields the final scalar (the streaming kernel is extended to retain per-candle stable values; the emitted `atr14` scalar stays byte-identical in meaning — the final observation).
2. **The percentile**: `p` = midrank percentile of the latest ATR-14 within the in-window observation set, `100 × (count(obs < latest) + 0.5 × count(obs = latest)) / N`, **rounded half-up to one decimal** — the rounded value is both the sealed byte and the bucket law's input, so every classification audits exactly against the sealed lane bytes by construction.
3. **The regime**, a **closed vocabulary** applied to the sealed one-decimal `p`: `p < 25 → "low"`; `25 ≤ p ≤ 75 → "normal"`; `75 < p ≤ 95 → "high"`; `p > 95 → "extreme"`.
4. **Insufficient data**: if fewer than **20** stable in-window ATR observations exist, the lane emits **no regime fields at all** (absent, never a guess); the adapter's D-AR-3 default then preserves today's behavior exactly. Disclosed: this branch is **unreachable in the composed pipeline** (the kernel emits no technical payload below 50 candles, which already yields ≥ ~36 observations; with the K ruling's 100-candle window, ~86) — it is defensive law, pinned by unit vectors only.

The lane payload (`TechnicalLensV1["payload"]`) gains exactly two optional fields: `atrRegime` (the closed 4-string vocabulary) and `atrPercentile` (the sealed one-decimal value; declared in `ENRICHMENT_DECIMAL_KEYS` alongside `atr14` per the no-raw-floats law). The governed lens contract (`enrichment-technical.schema.json`) is lenient over the `technical` sub-object and requires **no** schema `.json` change; this clause is the governed record of the closed vocabulary (a **ledger-carried** vocabulary — recorded as such in the FLPR-GOV walk, where the D-FLPR-3 precedent carried its vocabulary in the schema). New unit vectors pin the percentile formula (boundary vectors at p = 25.0, 75.0, 95.0 exactly, rounding cases at the band edges, tie cases, and the sub-20-observation absence).

**Adapter-identity determination (the EV3-GOV D-EV3-5(4) pattern).** The two additive optional observation fields extend the technical lane's emitted payload; **the owner expressly determines that this change is within the identity of adapter `afi-adapter-technical-local@1.0.0`** — no adapter re-version, no `providerInvocations[].adapter.adapterVersion` movement, no ProviderInstance or binding change. Any future non-additive change to the lane's normalization contract still re-versions under existing PBF/FLPR law.

**Scope-guard.** Exactly these two fields with exactly this law. If the executing change emits any other new lane field, alters `atr14`'s value or any existing payload byte for a given window, guesses a regime under insufficient data, or touches any other lane, it must not merge. Sweep-token and sentiment/news/aiMl fences (D-FLPR-5(2)) stand untouched.
