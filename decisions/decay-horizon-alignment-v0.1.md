## 3. D-DH-2 — The outcome-horizon derivation law

1. **Derivation.** For every scoring-context doc **captured at or after the cutover instant** (D-DH-2(3)), outcome-capture horizons are `{ceil(H/4), ceil(H/2), H}` minutes where `H = decayParams.halfLifeMinutes` as stamped on the doc at scoring time. Labels normalize as: whole hours render `"<n>h"`, sub-hour and non-whole-hour minutes render `"<n>m"` (H = 60 → `15m, 30m, 1h`; a swing-stamped doc would derive `3h, 6h, 12h`). The stamped value is the law — capture never re-resolves the registry, so the window used is auditable from the doc itself and never drifts from what the strategy declared when the signal was scored.
2. **Rationale (recorded, not re-decided elsewhere):** the qualification bound of §1.4 — no signal outlives one half-life under the profile's 0.5 threshold — makes `H` the outermost window that measures qualified signal life, and `{H/4, H/2}` the interior checkpoints. Windows are start-anchored at signal time (entry = close of the 5m candle at/just before capture, unchanged from v0).
3. **Cutover guard.** Docs captured **before** the cutover instant complete their capture under the legacy global set (`1h`, `4h`, `24h`) exactly as today, including 24h rows not yet mature — their windows were law when they were scored, and mixed-law rows for one signal are avoided. The cutover instant is the deploy timestamp of the D-DH-4 program's reactor image, recorded in the program PR (a constant in the capture script, not a runtime lookup).
4. **Fallbacks and overrides.** A doc with absent or malformed `decayParams` (none exist live; defensive only) falls back to the legacy global set, and the row records `horizonBasis: "legacy-global"`. An explicit `--horizons` CLI argument remains an operator override that bypasses derivation for that run (its values must still parse under the label grammar); the deployed Cloud Run Job passes none.
5. **No persistence-plane change:** capture continues to write only to `afi_signal_analytics.signal_outcomes` (MONGO-GOV plane rules honored; log-and-skip per-signal failure semantics unchanged; the `(signalId, horizon)` unique index unchanged).
